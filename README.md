# ⚡ CourseVault – Courses Dashboard

A modern and visually stunning **Course Management Dashboard** built using **Streamlit**.
Easily manage, analyze, and organize your course catalog with a powerful and intuitive interface.

---

## 🚀 Live Demo

👉 https://adarsh07a-courses-dashboard-api-app-qw80vo.streamlit.app/

---

## 📌 Features

### 📋 Course Management

* ➕ Add new courses
* ✏️ Edit existing courses
* 🗑️ Delete courses
* 📚 View all courses in a structured table

### 🔍 Smart Filtering

* Search by **title or instructor**
* Filter by **category, status, and price tier**

### 📊 Insights & Analytics

* 📈 Courses by category
* 💰 Price distribution (Budget / Standard / Premium)

### 🎨 Modern UI

* Clean and futuristic dark theme
* Responsive layout
* Interactive charts and tables

---

## 🛠️ Tech Stack

* **Frontend & Backend:** Streamlit
* **Data Handling:** Pandas
* **Storage:** JSON file
* **Language:** Python

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/coursevault.git
cd coursevault
```

### 2️⃣ Install dependencies

```
pip install -r requirements.txt
```

### 3️⃣ Run the app

```
streamlit run app.py
```
